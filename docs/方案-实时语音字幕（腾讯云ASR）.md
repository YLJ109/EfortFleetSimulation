# 方案 · 实时语音字幕（腾讯云实时语音识别 ASR）

> 2026-10-08 · 现场需求：连接云端 ASR 做实时语音转写，像**电影字幕**一样显示在 **3D 画面底部偏上**。

---

## 1. 范围

| | 内容 |
|---|---|
| **做** | 麦克风实时采集 → 云端流式识别 → 部分结果（边说边出）与最终句都以**字幕**形式叠在 3D 视口；一键开关；失败有明确原因 |
| **不做** | 语音指令控制机器人（**绝不**把识别文本接到运动链路）、录音留档、说话人分离、多路并发识别 |

★ **安全红线**：字幕是**只读显示**，不解析成任何指令，不写任何寄存器。语音→机器人动作一律不做。

## 2. 架构

```
浏览器麦克风 (getUserMedia)
  └─ AudioContext(16kHz) → ScriptProcessor → Float32→Int16 单声道 PCM
        │ 每 ~40ms 一帧（1280 字节）
        ▼
后端 WebSocket  /ws/asr        ← 同源同端口，免额外端口/跨域
  · 带内握手鉴权（首帧 {"type":"auth","token":...}，令牌不进查询串/访问日志）
  · 密钥只在后端 .env，**绝不下发浏览器**
        │
        ▼
腾讯云实时语音识别  wss://asr.cloud.tencent.com/asr/v2/<appid>?<签名参数>
        │ 上行：PCM 二进制帧；结束时发 {"type":"end"}
        ▼
下行结果 → {"partial": "...", "final": "...", "slice": 0|1|2}
        ▼
前端字幕层（MonitorLayout 的 .view 内，bottom 居中偏上）
```

**为什么让后端代理而不是浏览器直连腾讯云**：
① 密钥一旦下发浏览器就等于公开（本项目已因"硬编码口令"踩过一次）；
② 浏览器直连需要处理腾讯云的签名（SecretKey 必须进前端）——不可接受；
③ 后端代理可统一限流、单会话控制、审计留痕。

## 3. 腾讯云协议要点

- 端点 `wss://asr.cloud.tencent.com/asr/v2/{appid}?{params}`
- 待签名串 = `asr.cloud.tencent.com/asr/v2/{appid}?` + **按 key 升序**的 `k=v` 用 `&` 连接
  （★ 参与签名的值**不做 urlencode**）
- `signature = Base64(HMAC-SHA1(SecretKey, 待签名串))`
- 音频参数：`voice_format=1`（PCM）、16k / 16bit / **单声道**、`engine_model_type=16k_zh`
- 结束：发一帧文本 `{"type":"end"}`
- 下行：`result.slice_type` **0=整句开始 / 1=中间（部分结果）/ 2=整句结束**，
  `final=1` 表示整段会话结束；`code != 0` 是错误码（要在界面如实显示）

## 4. 前端字幕层设计

- 挂载点：`MonitorLayout.vue` 的 `.view` 内（与 `SafetyChip` 同一套浮层套路，自动跟随右栏折叠/窄屏）
- 位置：`left:50%; transform:translateX(-50%); bottom: 12%`（"底部偏上一点"，避开底部状态栏与左下角日志面板）
- 样式（电影字幕）：居中、`clamp(16px, 2.2vw, 30px)`、白色、2px 黑描边 + 半透明黑底圆角、`text-shadow`
- 两种文本：**部分结果**灰白（带呼吸光标，边识别边替换）；**最终句**亮白，停在屏上 N 秒后淡出
- 一句结束（slice_type=2）→ 转入"已定稿"队列，长句自动限宽换行（最多 2 行）
- 右上角一个 **麦克风开关**：未开始＝灰色 mic；识别中＝红色跳动；失败＝红色 + 悬停看原因
- 未配密钥时按钮可点但立即提示"未配置腾讯云密钥（见 .env）"——**不静默失败**

## 5. 配置（.env）

```
EFORT_ASR_PROVIDER=tencent          # 目前仅 tencent；留空=关闭该功能
EFORT_ASR_APPID=                    # 腾讯云 AppID（数字）
EFORT_ASR_SECRET_ID=                # 腾讯云 SecretId
EFORT_ASR_SECRET_KEY=               # 腾讯云 SecretKey（★ 只放后端，勿提交）
EFORT_ASR_ENGINE=16k_zh             # 引擎模型：16k_zh / 16k_en / 16k_zh_PY ...
```
`.env` 不被 git 跟踪；`.env.example` 只放空占位符。

## 6. 接口

| 方法 | 路径 | 说明 |
|---|---|---|
| `GET` | `/api/asr/config` | 功能是否可用 + 引擎 + **是否有密钥**（不回传密钥本身） |
| `WS` | `/ws/asr` | 音频上行 / 字幕下行；先过 Origin 检查，再要**控制令牌** |

## 7. 验收

| # | 项 | 判据 |
|---|---|---|
| 1 | 签名正确 | 单测：固定输入 → 签名与手工 HMAC-SHA1 结果一致；参数按 key 升序 |
| 2 | 未配密钥 | `/api/asr/config` 回 `enabled=false` + 明确原因，且**不含任何密钥片段** |
| 3 | 无令牌建连 | `/ws/asr` 以 4401 关闭 |
| 4 | 实时性 | 说话后 ≤1s 出现部分结果 |
| 5 | 字幕观感 | 居中、底部偏上、部分结果与最终句两态可辨、长句不溢出 |
| 6 | 安全 | 识别文本**不进入**任何控制链路；无麦克风权限时给明确提示 |
