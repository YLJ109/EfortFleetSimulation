## 4. 明确**没有做**的（附理由，不盲改）

| 编号 | 项 | 为什么不做 |
|---|---|---|
| **B2** | 把"等完成位"移出 `motion._exec_lock` | 这条锁正是 §5.3「防半截状态」的**安全互锁**：锁内跨"写速度→写目标→回读→settle→触发→等完成位"是为了保证**同一条指令序列原子**。把等待移出锁，会让别的下发插进"已触发、未确认"的窗口 —— 在真机上就是**两个动作打架**。按 AGENTS §5「硬口径与禁区」，这种改动必须**单独出方案 + 全量回归 + 现场验证**，不能和本次一起顺手改。 |
| **A6** | 把控制令牌从 localStorage 挪走 | 已核实**当前没有 XSS 注入面**：全前端仅一处 `v-html`，内容是**内置图标表**（`ICONS[props.name]`），不接任何用户输入；无 `eval`/`new Function`/`innerHTML`。改成"仅内存持有"会带来**刷新即掉线**的体验回退，却不改变"页面被 XSS 时令牌同样可用"的本质 —— 属于**没有真实收益的改动**，故不改。 |
| **B1 根治** | `/run-file` 异步化（起线程 + 返回 run_id） | 前端**依赖响应体里的逐步结果**（`d.steps` / `d.count` / `fileResult` 渲染每步成败）。异步化必须同时把界面改成从 `/control/run-state` 读逐步结果 —— 是**UI + 接口一起改**的独立任务。本次先按 §2 止血。 |

## 5. 现场要改的（部署提醒）

1. **默认只绑本机**：浏览器在**同一台机器**上用 `http://localhost:8000` 或 `http://127.0.0.1:8000` 访问，一切照旧。
2. 若一直从**别的电脑**开这个网页（`http://<这台机器的名字>:8000`），需要在 `.env` 里：
   - 后端：`EFORT_HOST=0.0.0.0`
   - 相机：`EFORT_CAMERA_HOST=0.0.0.0`（**并强烈建议**同时设 `EFORT_CAMERA_TOKEN` + 前端 `VITE_CAMERA_TOKEN` 为同一串）
3. 相机服务改完要**重启**（`scripts\start_camera.bat`）；后端改动要**重启后端**。
