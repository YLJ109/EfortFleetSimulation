# 方案：逐格约束解析（「某格不能拿 / 某格不能放」）—— 分拣·AI 通用

> 2026-10-10 用户口径：
> ①「B5、B9 禁止摆放物体」②「从 A 区拿三个蓝、两个绿、一个红放到 B 区」
> ③「我有可能 B6 不能放，有可能 A4 不能拿，A5 不能放等等这种**无规则的要求**，保证全部能解析」

---

## 1. 现状（先说清能力边界）

| 说法 | 现在 | 结论 |
|---|---|---|
| 「三个蓝、两个绿、一个红」 | `move_quota` 已支持（中文/阿拉伯数字） | ✅ 已能解析 |
| 「放到 B 区」 | 配额搬运必须给**颜色列**或整区 | ✅ 已能解析 |
| 「按排序摆放」 | 落位本来就是**按颜色列 + 列内按行序填空位** | ✅ 已是有序（本方案沿用此定义） |
| **「A4 不能拿 / A5 不能放 / B6 不能放 / B5、B9 禁止摆放物体」** | **完全没有这个概念** | ❌ 说了被**静默忽略** —— 最危险的一种"假装听懂" |

本方案补齐最后一行，并且**按"无规则"来做**：任意 A/B 格、任意个数、任意组合、任意语序。

---

## 2. 约束模型（统一一种，落到 plan 里）

```json
"ban": { "from": ["A4"], "to": ["A5", "B6", "B5", "B9"] }
```

- `ban.from` = **不能取料**的格；`ban.to` = **不能放料**的格。
- 只认 **A1–A9 / B1–B9**（与 38 点位同一套格号），其它一律不猜。
- ★ **作用域 = 这一条指令内有效**（不写全局配置）。理由：**井字棋要用满 B1–B9**，
  全局持久会直接把井字棋弄坏；临时约束说一次管一次，零副作用。
  （要"长期禁放"就做成界面开关 + 井字棋豁免，另立方案。）

---

## 3. 解析规则（要保证"全部能解析"）

### 3.1 支持的说法（都要命中的）

| 说法 | 结果 |
|---|---|
| `A4不能拿` / `A4不要拿` / `不要拿A4` / `禁止取A1` / `A2不能取` | `from += [A4/A1/A2]` |
| `A5不能放` / `B6不能放` / `禁止放B7` / `B7不要放` / `不放B3` | `to += [...]` |
| `B5、B9禁止摆放物体`（**先枚举、后动词**） | `to += [B5, B9]` |
| `A4不能拿，A5不能放`（一句里两个方向） | `from += [A4]`，`to += [A5]` |
| `B3不要放和A2不要拿` | 各自方向正确 |
| `B5和B9不能放` | `to += [B5, B9]` |
| 只说 `B5禁止摆放`（无"物体"等词） | `to += [B5]` |

**方向判定**：句段里出现「放/摆」类 → `to`；出现「拿/取/动」类 → `from`；
只出现「禁止/不许/不能」而无动词 → **默认 `to`（禁放）**（"禁止摆放"最常见，且禁放比禁取安全）。

### 3.2 关键工程点

1. **先切句段，再判方向**：按 `。；;\n` 切大段 → 段内按 `，,、` 切小段。
   小段自己带动词就自己判；**只带格号的裸小段**（如 `B5、B9`）**继承后面那一小段的方向**
   —— 这是"先枚举后动词"能解析的关键。
2. **必须把约束短语从原文里剥掉**再走原有的格位/颜色解析：
   否则「B6不能放」里的 `B6` 会污染"放到哪里"，把目标解析歪。
3. **解析不了就明说**：说了"不能放 B0"这种非法格号 → **报错**，不静默忽略。

## 4. 执行侧（说到做到）

| 动作 | 行为 |
|---|---|
| `move_one`（单件） | 源格在 `ban.from` → **拒绝**（"你指定了 A4 不能拿"）；目标在 `ban.to` → 拒绝并**列出可用格** |
| `move_all` / `move_quota` | 取件候选里**剔除** `ban.from`；落位**跳过** `ban.to` |
| 落位跳过 | 沿用"颜色列内按行序取第一个空位"，**跳过被禁的格**；跳过要在界面/日志**如实显示** |
| 列内可用格被禁完 | 明确报 `列内可用格已用尽（禁放了 N 个）`，**不硬塞**也不静默改放别处 |
| 分拣流程（三色分拣页） | **不受影响**（默认无约束 → `skip=None`，行为与现在逐字一致） |
| 井字棋 | **不受影响**（B1–B9 全可用） |

---

## 5. 不做什么

- **不做全局持久禁放**（会破坏井字棋；要就用界面开关另立方案）。
- **不改判色阈值/算法**、不动速度/围栏/互锁。
- **不做"自动挪到别的颜色列"** —— 禁放导致放不下时如实报，不替用户换位。
- **不猜非法格号**（B0、A10、C3 一律报错）。
- 本轮**不做 3D/棋盘上的禁用格高亮**（先在**计划卡 + 状态**里明写，界面标注列为后续）。

## 6. 验收

| 场景 | 期望 |
|---|---|
| 「从A区拿三个蓝两个绿一个红放到B区，B5和B9不能放」 | 计划卡明写"禁用放料：B5、B9"；落位跳过这两格 |
| 「A4不能拿，把A4放到B1」 | **直接拒绝**（源格被禁） |
| 「A4不能拿，A5不能放」 | `ban.from=[A4]`、`ban.to=[A5]`，两个方向都对 |
| 「B0不能放」 | 报错（非法格号），不静默忽略 |
| 禁放把某颜色列占满 | 报"列内可用格已用尽（禁放了 N 个）"，不硬塞 |
| 分拣页三色分拣 | 行为不变（回归全绿） |

回归钉：`nl_intent` 多说法表、`pick_target_slot(skip_slots=)`、`move_one` 命中禁取即拒、前端源码钉。
