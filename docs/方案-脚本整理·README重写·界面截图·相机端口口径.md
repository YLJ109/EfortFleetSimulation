## 4. 相机"端口"口径（**口径不明，需你拍板**）

### 事实（当前实现）
- 视觉服务是**独立进程**，靠一个 **HTTP 端口 8100** 提供：MJPEG 画面 `/stream`、判色 `/vision/detect`、存图/标定。前端面板与后端都要访问它。
- 我刚把它的**默认绑定改成 `127.0.0.1`**（原来 `0.0.0.0`）→ **已经不会对局域网开端口**；本机这一个端口仍在用。
- 工业相机（海康 GigE）走网络，**本来就要网络**；USB 相机**不需要网络**，现在默认 `EFORT_CAMERA_KIND=usb`，连 MVS SDK 都不加载。

### 你那句话我读出两种意思，请选一个

| 选项 | 含义 | 要做什么 | 代价 |
|---|---|---|---|
| **甲（我猜最可能是这个）** | "USB 相机**不该对外开端口**" —— 现状已满足，只是要**再完善** | ① 默认 `127.0.0.1`（已做）；② 补：`/status` 与启动日志**明确打印绑定地址+是否仅本机**；③ `doctor.bat` 加"端口是否被占用/是否有重复实例"；④ README 写清"USB 不需要网络，工业相机才需要" | 小，纯完善 |
| **乙** | "USB 相机**连这一个端口都不想要**"（比如公司不允许再开端口） | 由**后端代理**相机流：前端不再直连 `:8100`，改走 `:8000/api/camera/*`（后端转发 MJPEG/判色请求），`8100` 只绑本机甚至可关 | 中等：动前端取流路径 + 后端加转发 + 回归（有性能/缓冲坑） |

> 我倾向 **甲**（现状已达成你的目标，只是把它说清 + 加固）；若你确实要 **乙**，我另出一份专门方案（含"不做什么"与回归）。
