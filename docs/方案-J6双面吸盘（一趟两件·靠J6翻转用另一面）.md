## 1. 目标（一句话）

把 J6 工装的**两面**都用起来：一趟**两面各吸一件**，靠 **J6 翻转**切换用哪一面，
一趟送检（正/反各拍 2 帧）、一趟把两件按逻辑落位，**两件放完才回起点**。

## 2. 流程口径（一趟 = 两件）

| 步 | 动作 | 硬约束 |
|---|---|---|
| 1 | 正上位 → 下压取 **A1**（**下面那面**吸住）→ 抬起 | 原料位**严禁旋转** |
| 2 | 在**正上位** J6 转到「**反面**」点（用户示教） | 原料位（A 区格位本身）**严禁**旋转 · 其余位置均可 |
| 3 | → 取 **A2**（**上面那面**吸住）→ 抬起 | 原料位**严禁旋转** |
| 4 | 到 **C 检测位**：**正面 2 帧 → 投票**；J6 转到反面 → **反面 2 帧 → 投票**（共 4 帧、**2 个独立结论**） | 两件可**不同色**；也可能是**无效色/判不出** |
| 5 | **先放有效的那件**（按颜色/摆法落位） | 无效件先不处理 |
| 6 | **无效件原路放回它自己的 A 原位** | 即现有"无效色 → 放回原位"口径 |
| 7 | 之后**直接去正上位**（**不再回起点**）继续下一趟 | — |
| 8 | **两件都放完 → 回起点** | — |

**件数**：9 件 = **4 趟×2 件 + 最后 1 趟 1 件**（用户："第九次只需要一次"）。
**面切换**：全程**靠 J6 旋转**（用户："那两个通过旋转"）。

## 3. 概念与状态（必须新增的东西）

| 概念 | 现状 | 要变成 |

| "哪一面在吸" | 不存在 | **由流程推断**（现场无真空传感器）→ 3D/界面**必须标注为推断** |
| J6 正面/反面 | 无 | **两个普通示教点位**（用户自己记，像 A1/A2，**可删可改**）—— 不新造存储机制 |

| 3D | 手上**一块**料 | 手上**上下各一块**料；J6 旋转时**跟着转** |

## 5. 气路口径（**已确认：只有一路真空 + 用"瞬时复吸"解决**）

### 5.1 硬件事实
全项目**只有一路**吸放 IO（`io.DOut[8]`，配合 210 里 `ro_b[1]/wo_b[1]` 吸气、`ro_b[2]/wo_b[2]` 放气）。
→ 两面吸盘**共用这一路真空**：**两件可以同时被吸住**，但**不能独立放掉其中一件**。

> ★ **更正（我上一轮说错了）**：我上一轮写"只有一路真空 ⇒ 一趟两件做不了"，**过于悲观、是错的**。
>   用户口径证明：**一趟两件做得到** —— 靠下面这套"**取第二件不断真空 + 放件时瞬时复吸**"的时序。

### 5.2 用户口径的时序（每一步都照做）

| 步 | 气路动作 | 为什么 |
|---|---|---|
| 取 **A1**（第 1 件，下面那面） | 正常：`吸` → （等吸牢） | 建立真空 |
| 在**正上位**转 J6 到「反面」 | **不碰气路** | 保持第 1 件不掉 |
| 取 **A2**（第 2 件，上面那面） | ★ **不放气、也不"停止吸"** —— 就是**保持吸气**直接压下去取 | 一断真空第 1 件就掉了 |
| 送 C 检测位、正/反各拍 2 帧 | **不碰气路** | 两件都靠同一路真空吊着 |
| **放件**（原地、不移动）： | ★ **`停止吸` → `放` → `停止放` → 立刻 `吸`** | `停止吸`+`放` 把要放的那件**放到台面/料上**；用户口径："**方块在物体上面不会掉落**"；同时**另一件会一起失真空** → 所以**立刻 `吸`** 把它重新吸住 |
| 放另一件 | 同样四步再来一次 | 一次只放一件 |
| 收尾 / 异常 | 按既有口径（异常**必须**两路全关，不许悬空带料） | — |

**关键约束**：放件那 4 个气路动作 **必须"原地"连续做完** ——
**中间不得插入任何移动、也不得插入长等待**（窗口越短，悬挂那件越安全）。

### 5.3 ⚠ 必须如实写明的风险（不掩盖）
- "`停止吸`→`放`→`停止放`→`立刻吸`"这个窗口里，**悬挂着的那一件是靠残余负压 + 惯性保持的**；
  如果窗口偏长（网络/触发延迟、服务程序里多余的 `DWELL`），**它可能掉**。
- 因此：① 窗口内**不加 dwell**；② 现场必须 **5% 慢速、单点先验**；③ 日志与 3D 里如实标注
  "此处为**瞬时复吸**，非两路独立真空"；④ 若以后现场能接**两路独立气路**，这个风险**彻底消失**（建议列为后续小改）。

## 6. 安全护栏（这类项目必须钉死，建议做成回归钉）

1. **旋转位置黑名单（2026-10-11 更新口径）**：`J6 翻转` **只禁止落在原料位（A 区格位本身，如 A1…A9）**，
   **其余一切位置（正上位 / J6正反面 / C检测 / 摄像头位 / 起点 / home…）都允许**；
   凡在**原料位**出现的"带旋转的下发"→ 后端**直接拒绝**并写明原因（**原料位严禁旋转**，钉子，改不掉）。
   判据 = 黑名单函数 `is_raw_material_slot`（不是旧的"只允许 正上位/摄像头/起点"白名单）。
2. 翻转是**真运动**：限位 / 可达 / 围栏 / 碰撞全过（用现有**残影预演**判定）。
3. **速度**：真机验证一律 **5%**，单点慢速。
4. **失败即停**：取到一半/放了一半 → 先**放气避免悬空带料**，再回起点（沿用现有口径）。
5. **料位传感器没有**：所有"吸住了/哪面在吸"都是**流程推断**，界面与 3D 必须如实标注。

## 7. 不做什么（边界）

- ❌ 不改示教器 / 210 的**点动服务**语义（若走 §5-A，只**新增**一路吸放服务，不动原有的）。
- ❌ 不改 `motion._exec_lock` / 速度反算 / 触发位时序。
- ❌ 不引入新框架、不改点位库的存储格式（正/反面就是两个**普通点位**）。
- ❌ 不自己算"J6+180°"：**正/反面姿态由用户示教**（用户口径 e）。
- ❌ 不在没真机验证前把双面流程设为默认；先**空跑**，再**单点 5% 真机**。

## 9. 回归钉（新增，实施时加）

1. **原料位严禁旋转**：构造"在 A 格位下发带旋转的姿态" → 必须 409 且原因写明。
2. **双槽夹持**：`hold_lower`/`hold_upper` 的置位/清除/异常收尾（异常必须两路都放气）。
3. **4 帧 = 2 组**：正面 2 帧、反面 2 帧，各自投票；**不能**把 4 帧混成一次投票。
4. **先放有效、无效原路放回**：有效件落 B 格；无效件回它自己的 A 格；**配额只对有效件扣**。
5. **两件放完才回起点**：编排顺序钉死（源码位置断言）。
