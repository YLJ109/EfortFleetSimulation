## 1. 目标（一句话）

把 J6 工装的**两面**都用起来：一趟**两面各吸一件**，靠 **J6 翻转**切换用哪一面，
一趟送检（正/反各拍 2 帧）、一趟把两件按逻辑落位，**两件放完才回起点**。

## 2. 流程口径（一趟 = 两件）

| 步 | 动作 | 硬约束 |
|---|---|---|
| 1 | 正上位 → 下压取 **A1**（**下面那面**吸住）→ 抬起 | 原料位**严禁旋转** |
| 2 | 在**正上位** J6 转到「**反面**」点（用户示教） | 原料位（A 区格位本身）**严禁**旋转 · 其余位置均可 |
| 3 | → 取 **A2**（**上面那面**吸住）→ 抬起 | 原料位**严禁旋转** |
| 4 | 到 **C 检测位**：**正面 2 帧 → 投票**；J6 转到反面 → **反面 2 帧 → 投票**（共 4 帧、**2 个独立结论**） | 两件可**不同色**；也可能是**无效色/判不出** |
| 5 | **先放有效的那件**（按颜色/摆法落位） | 无效件先不处理 |
| 6 | **无效件原路放回它自己的 A 原位** | 即现有"无效色 → 放回原位"口径 |
| 7 | 之后**直接去正上位**（**不再回起点**）继续下一趟 | — |
| 8 | **两件都放完 → 回起点** | — |

**件数**：9 件 = **4 趟×2 件 + 最后 1 趟 1 件**（用户："第九次只需要一次"）。
**面切换**：全程**靠 J6 旋转**（用户："那两个通过旋转"）。

## 3. 概念与状态（必须新增的东西）

| "哪一面在吸" | 不存在 | **由流程推断**（现场无真空传感器）→ 3D/界面**必须标注为推断** |
| J6 正面/反面 | 无 | **两个普通示教点位**（用户自己记，像 A1/A2，**可删可改**）—— 不新造存储机制 |

## 5. 气路口径（**2026-10-11 前提更正：两面各自独立**）

> ★★ **前提更正（务必先读）**：本文旧版 §5 写的是"**全项目只有一路真空（io.DOut[8]），
>   两面共用**，靠'瞬时复吸'解决" —— **该前提是错的**，已被现场与用户更新后的 210 程序证实。
>   用户 2026-10-11 在示教器上更新了 210，并给出权威位表（原话）：
>   「之前 210 程序的 **0 是点位移动，1 是吸气，2 是停止吸气，3 是放气，4 是停止放气**，
>     新添加了 **5 是吸反面的气，6 停止吸反面，7 是放气反面的，8 是停止放气了**」
>   ⇒ **两面板各自独立气路**：下板/正面 = 40135.Bit1~4（索引 1~4）；
>     反面/上板 = Bit5~8（索引 5~8）。位号**唯一来源** = `backend/app/services/modbus.py` 的
>     `VAC_ACTIONS`（本文件与代码注释均对齐它）。

### 5.1 硬件事实（更正后）
- 下板（正面）与反面（上板）**各一路独立真空/吹气**：下板 1~4 位、反面 5~8 位。
- ⇒ **放一件不会影响另一件**（可各自独立吸/放）。
- ★ 此前"反面吸不到"的**真正原因**：我们发「吸气」(Bit1) 驱动的是**下板那一路**，
  **反面的那一路 (Bit5) 从未被驱动**。（旧版误判为"没有 off→on 边沿"，
  据此加的"停止吸 → 立刻吸"**是错的，已删除**。）

### 5.2 用户口径的时序（每一步都照做）

| 步 | 气路动作 | 为什么 |
|---|---|---|
| 取 **A1**（第 1 件，下板/正面） | `吸`(Bit1) →（等吸牢） | 建立下板真空 |
| 在**正上位**转 J6 到「反面」 | **不碰气路** | 保持第 1 件不掉 |
| 取 **A2**（第 2 件，上板/反面） | ★ **`吸反面的气`(Bit5)** | 两面独立：吸反面那一路，**不碰下板**、第 1 件不受影响 |
| 送 C 检测位、正/反各拍 2 帧 | **不碰气路** | 两件各靠自己的那一路吊着 |
| 放正面那件（下板） | `停止吸(2) → 放(3) → 停止放(4)` | **只碰下板那一路**，不碰反面那路 |
| 放反面那件（上板） | `停止吸反面(6) → 放反面(7) → 停止放反面(8)` | **只碰反面那一路**，不碰下板那路 |
| 收尾 / 异常 | 两面**各按自己那路收气**（下板 2/4、反面 6/8 按需） | **不许有件悬空失真空** |

**关键约束**：放件三步 `停止吸 → 放 → 停止放` **原地连续做完**，**中间不插入移动**；
取 A2 的 `吸反面的气` 也**只碰反面那一路**（下板那路保持不动）。

### 5.3 复吸已取消（安全上的净改善）
- 旧版为"共用一路真空"设计的「**瞬时复吸**四步（停止吸→放→停止放→**立刻吸**）」**已取消**：
  两面独立 → 放一件不再连累另一件 → **不需要复吸**，原"第 1 件瞬时失真空"的风险随之消失。
- 相应地，`_dual_drop` 由四步变**三步**、`_put_back` 的 `keep`（复吸开关）**已移除**。

### 5.4 取第 2 件改发"反面那一路吸气"（本轮更正）

**用户原话 + 位表**：见本文 §5 顶部。

- **根因（已证实）**：项目一直按"两面共用一路真空"实现 —— 我们发「吸气」驱动的是**下板那一路**，
  **反面的那一路从未被驱动** → 反面吸不到。
- **修正**：取 A2 由「上方 → 下落 → **停止吸 → 立刻吸**」改为
  「上方 → 下落 → **`吸反面的气`(Bit5) → 等吸牢 → 抬起**」（`face=FACE_BACK`）。
  - 删除旧的"停止吸 → 立刻吸"两步（前提已被推翻，不需要造 off→on 边沿）；
  - 单件趟（`len(trip)==1`）与第 1 件（下板）流程**逐字不变**（零回归）；
  - 空跑（`dry`）走**同一顺序**，只是 `_air` 内只 `_set` 记阶段、不下发。

**回归钉**（`backend/tests/test_double_face.py`）：
顺序钉（上方→下落→吸反面→抬起）+ 反证钉（不得再出现停止吸/复吸）
+ 零回归钉（第 1 件 / 单件趟逐字不变）+ 位图钉（8 动作 → 位号）
+ 独立钉（正/反面位集合不相交）+ 唯一映射口钉（`_air_action`）。

## 6. 安全护栏（这类项目必须钉死，建议做成回归钉）

1. **旋转位置黑名单（2026-10-11 更新口径）**：`J6 翻转` **只禁止落在原料位（A 区格位本身，如 A1…A9）**，
   **其余一切位置（正上位 / J6正反面 / C检测 / 摄像头位 / 起点 / home…）都允许**；
   凡在**原料位**出现的"带旋转的下发"→ 后端**直接拒绝**并写明原因（**原料位严禁旋转**，钉子，改不掉）。
   判据 = 黑名单函数 `is_raw_material_slot`（不是旧的"只允许 正上位/摄像头/起点"白名单）。
2. 翻转是**真运动**：限位 / 可达 / 围栏 / 碰撞全过（用现有**残影预演**判定）。
3. **速度**：真机验证一律 **5%**，单点慢速。
4. **失败即停**：取到一半/放了一半 → 先**放气避免悬空带料**，再回起点（沿用现有口径）。
5. **料位传感器没有**：所有"吸住了/哪面在吸"都是**流程推断**，界面与 3D 必须如实标注。

## 11. 面语义 `keep`（去原料位保持当前面、不旋转）与"送检前经正上位"（2026-10-11 落地）

> 用户口径（本轮 · **原话**）：
> 「1.对，但是原位禁止旋转」
> 「2.A和B都要啊，取两个然后去C检测两个检测完再放目标位置」
> 「如果正面保持正面，如果反面保持反面，如果都不是调整接近哪个点就那个」

### 11.1 需求 1：新增面语义 `face="keep"`（**去原料位不翻面**）

**背景（用户报的现象）**：让"反面的件"去原料位，它**总被弄成正面**。
根因：**18 个原料位严禁旋转**（黑名单，§6-1），而"点到点移动"过去要么按**该点自身正面**下发
（= 把反面件翻回正面），要么按**该件反面**下发（= 在原料位上做 ±180 翻转，**违反禁转**）。
两条路都不对 —— 所以要新增第三种面语义：**保持当前面、不旋转**。

**`keep` 的精确语义（严格按用户原话）**

| 当前面 | `keep` 的结果（J6） |
|---|---|
| **正面** | **保持正面** = 该点自身 J6（**不写死 0**） |
| **反面** | **保持反面** = 该点自身 J6 ∓180 归一（**不写死 −180**） |
| **都不是**（未知/判不出） | 取**离当前实时 J6 更近**的那一面（"调整接近哪个点就那个"） |

- 实现上：**J1~J5 用该点位自身的值**，J6 = `keep_j6(该点自身 J6, 当前实时 J6)`；
  **全程不产生"主动翻面"动作** → 与"原料位严禁旋转"**完全相容**。
- ★ **禁转口径一个字未改**：`_rotation_guard` / `is_raw_material_slot`（18 原位黑名单）
  原样保留；`keep` 走的是**普通 `_move`**（不是翻转下发），天然**不触犯**这道黑名单。

**落地点（唯一解算口）**

| 位置 | 改动 |
|---|---|
| `backend/app/services/sorting.py::resolve_target_joints(..., face="keep")` | 新增 `keep` 分派；纯函数 `keep_j6` / `keep_face` / `resolve_face` / `_current_j6_from` |
| `backend/app/api/sorting.py::_move` | `state.face` 经 `S.resolve_face` **如实记录**实际保持的面（keep 也不会被谎报成正面） |
| `_put_back(...)` 的"下落（去原料位）" | `face=face` → **`face=S.FACE_KEEP`**（正上方/气路仍用该件的面） |
| `_run_sorting_dual_face` 取第 1 件"下落" | 补 **`face=S.FACE_KEEP`**（此处当前=正面 → 等价正面） |
| `_run_sorting_dual_face` 取第 2 件"下落" | `face=S.FACE_BACK` → **`face=S.FACE_KEEP`**（保持当前反面、不翻回正面） |

> 取第 2 件的**正上位**移动（`A{j}上`）与**气路**仍走 `face=FACE_BACK`（正上位允许旋转）；
> 只有"**去原料位**"那一步改成 `keep`。

### 11.2 需求 2：送检前要走"统一的正上位"（A 和 B **都要**）—— **查证结果：无此点位，未接入**

- 用户的 A（已有）：每次取料后先抬到**该料自己的正上方**（`A{i}上`）——**保留**。
- 用户的 B（新增）：取完两个件后、去 C 检测前，先经过"**统一的正上位**"。
- ★ **查证结果（不臆造点名）**：点位库里**没有**名为「正上位」的统一点位 ——
  `S.expected_points()` 的"正上位"是**每格各自**的 `A{i}上` / `B{i}上`（共 36 个）；
  `/api/points` 实测（46 个点位）中也无「正上位」（只有历史遗留的 `(1,2)正上位` 这种旧式格号，非统一点）。
  ⇒ 按用户口径 **不猜、不臆造点名** → **保持现状**：只保留"各料自己的正上方"，
  **不新增**"统一正上位"点。**待用户给出点名后再接**（接入点 = ④ 送检那次移动的位置）。

### 11.3 送检 / 放料次序（**不变**）

- 拍照面序（唯一口径 `S.faces_for_capture`）：**先反面 → 后正面**；

### 12.6 双重保险：**入口显式声明 + 原语兜底**（2026-10-11 本轮）

§12.2 的 9 个入口都显式调 `S.face_for_target`（**入口显式声明**）—— 但它依赖"每个入口都记得调"，
**未来新增一条下发路径若漏调，就又会从原料位翻面**。故本轮再加**第二层**：

> 在**原语层** `services/sorting.py::resolve_target_joints` 内部，凡 `name` 是**原料位**
> （`is_raw_material_slot`：A1…A9 / B1…B9，共 18 个）→ **强制 `face = FACE_KEEP`**（**无视**传入的 `front`/`back`），
> 再按 keep 解算。

| 层 | 位置 | 角色 | 对非原料位 |
|---|---|---|---|
| **入口显式声明** | `S.face_for_target(name, face)`（9 个入口各调一次） | 谁去原料位就在入口声明 `keep`，**可读、可追溯** | **原样透传** |
| **原语兜底** | `S.resolve_target_joints` 内部 | **最后一道保险**：任何路径最终都经此解算，漏调入口层也**到不了原料位翻面** | **原样透传** |

- ★ **这样以后新增路径自动安全**：只要新路径的"点位 → 目标"仍走**唯一解算入口** `resolve_target_joints`
  （本项目的既定口径，见 `test_no_full_pose_entry_for_j6_face_points_source`），即便**忘了**在入口层调 `face_for_target`，
  原语层也会把原料位兜成 `keep` —— **结构上不可能在原料位翻面**。
- ★ **口径不变**：`keep` 的三种情形（当前正面→保持正面 / 当前反面→保持反面 / 判不出→取离该点自身 J6 更近的一面）
  **逐字未改**；`is_raw_material_slot` 与 `_rotation_guard`（18 原料位禁转黑名单）**一个字节未改**；
  非原料位（`front` 原样 6 值 / `back` ∓180 / `J6正面/反面` 原地切面）**逐字未变**。
- ★ 回归钉（`backend/tests/test_double_face.py`）：
  · `test_resolve_target_joints_forces_keep_on_raw_slot` —— **原语兜底钉**：`A1`/`B5` 传 `front`/`back` 的结果**都等于** `keep`；
  · `test_resolve_target_joints_non_raw_unaffected_by_fallback` —— **零回归钉**：`C检测`/`A1上` 的 `front`/`back` 逐字不变；
  · `test_face_for_target_neutralizes_front_and_back_at_raw_slot`（**更新**：原"直接按正面调会变回 0"的反证，
    因原语兜底**已失效** → 改为"直接按正面调也被兜成 keep、仍保持反面"）。
